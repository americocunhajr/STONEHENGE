# Basins of attraction

Maps basins for the piezo-magneto-elastic harvester by integrating grids of initial displacement and velocity and classifying the asymptotic responses.

## Files and entry points

- main.cpp — C++ simulation and classification driver
- header.cpp / header.h — numerical and auxiliary functions
- ploting.m, graph_type1.m, graph_contourf_pnt.m, myplot_params.m — MATLAB visualization

## Running and dependencies

The simulation is written in C++ and the visualization routines are in MATLAB. Check local output paths and C++ compiler settings before running.

The existing numerical code was not modified or independently execution-tested as part of this documentation update.
