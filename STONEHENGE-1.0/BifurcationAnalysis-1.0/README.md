# Bifurcation analysis

Computes the response of the bistable harvester as excitation amplitude varies at several forcing frequencies, including increasing and decreasing parameter sweeps.

## Files and entry points

- main_3D_bifurcation.m — main MATLAB driver
- bifurcation_3d.m — parameter sweeps and data assembly
- plot_3D_bifurcation.m — three-dimensional bifurcation visualization
- piezomagbeam_asymmetric.m — governing model

## Running and dependencies

Set the parameter ranges and output name in the main script.

The existing numerical code was not modified or independently execution-tested as part of this documentation update.
