# Displacement amplification

Numerically studies a base-excited bistable energy harvester with a displacement-amplification mechanism and two mechanically coupled degrees of freedom.

## Files and entry points

- main_bistable_amplification_base.m — parameters, five-state electromechanical model, time integration, and visualization

## Running and dependencies

This is a focused, standalone MATLAB example with parameters in SI units.

The existing numerical code was not modified or independently execution-tested as part of this documentation update.
