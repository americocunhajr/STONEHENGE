# Poincaré sections

Constructs phase portraits and stroboscopic Poincaré sections for the bistable harvester over multiple excitation amplitudes.

## Files and entry points

- main_PhasePortait_Poincare.m — main sweep and plotting script
- phase_portait.m — phase-portrait integration
- poincare.m — samples once per forcing period
- piezomagbeam_asymmetric.m — model dynamics

## Running and dependencies

The original filename Main_PhasePortait is intentionally preserved despite its spelling. Run the main MATLAB script from this directory.

The existing numerical code was not modified or independently execution-tested as part of this documentation update.
