# Resonance curves

Computes frequency-response curves of the classical bistable piezo-magneto-elastic harvester under harmonic forcing.

## Files and entry points

- main_piezomagbeam_resocurves.m — frequency-sweep simulation
- piezomagbeam.m — harvester equations
- plot_resocurves.m — visualization

## Running and dependencies

The MATLAB driver defines the forcing parameters and output case name.

The existing numerical code was not modified or independently execution-tested as part of this documentation update.
